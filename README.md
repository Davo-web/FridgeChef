# FridgeChef

> Скажи, что есть в холодильнике, и получи рецепты, которые можно приготовить прямо сейчас.

**Статус:** в разработке (планирование и старт)

FridgeChef - учебный pet-проект на React: поиск рецептов по ингредиентам. Пользователь добавляет продукты (курица, рис, лук), приложение показывает блюда, где они используются, отсортированные по числу совпадений.

Проект создаётся как практика параллельно с изучением React.

## Цели проекта

- Закрепить основы React на реальном приложении
- Научиться работать с внешним API, асинхронностью
- Проект для портфолио

## Планируемый функционал

- Поиск рецептов по одному и нескольким ингредиентам
- Теги выбранных ингредиентов (добавление и удаление)
- Состояния загрузки, ошибки и «ничего не найдено»
- Страница рецепта: ингредиенты с количеством и шаги приготовления
- Избранные рецепты с сохранением в `localStorage`
- Автодополнение названий ингредиентов
- Сортировка по числу совпавших ингредиентов

## Планируемый стек

| Что | Зачем |

## Идея поиска по нескольким ингредиентам

Бесплатный эндпоинт TheMealDB `filter.php` принимает только один ингредиент за запрос. План:

1. Отправить запросы по каждому ингредиенту параллельно через `Promise.all`.
2. Пересечь результаты на клиенте по `idMeal`.
3. Отсортировать рецепты по числу совпадений.
